03 · CHATBOT

Thấy hệ thống đang dựa vào đâu

Web chatbot FastAPI + Server-Sent Events, dùng chung pipeline với bản chấm điểm. Không cần bước build, server Python phục vụ trực tiếp.

  • Nguồn đến trước chữ: panel tài liệu hiện ngay khi truy xuất xong.
  • Hiểu câu hỏi nối tiếp: "Ai là người sáng lập?" được viết lại theo lịch sử chat.
  • Panel hiệu năng: thời gian từng bước của mỗi câu trả lời.
  • Lỗi dễ hiểu: gateway, mất mạng, hết hạn mức, kèm nút Thử lại.

Chạy tốt trên điện thoại

Trên màn hình hẹp, lịch sử và nguồn chuyển thành ngăn kéo. Lịch sử chat lưu trong trình duyệt, không cần đăng nhập.

04 · CHẠY THỬ

Ba lệnh để chạy trên máy bạn

Cần Python 3.10+ và key gateway của cuộc thi. Chatbot cần server Python và key nên không chạy trực tiếp trên trang này.

1. Cài đặt

# Windows; macOS/Linux dùng source .venv/bin/activate
python -m venv .venv
.venv\Scripts\activate
python scripts/install.py --local
copy .env.example .env

Điền key vào .env. Lần đầu sẽ tải reranker khoảng 2 GB.

2. Chatbot

python app/server.py
# mở http://127.0.0.1:8000

Đợi dòng Uvicorn running. Bản dự phòng: python -m streamlit run app/chat.py.

3. Chấm điểm

neorag run train --no-judge
neorag run public_test

Mặc định chạy MyPipeline với configs/pipeline.toml. Báo cáo ở outputs/eval_*/.
